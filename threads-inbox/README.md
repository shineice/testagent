# Threads Inbox：每日貼文 → 行動計劃

每天把「還沒看、但覺得值得」的 Threads 貼文丟給 Claude，Claude 會產出行動計劃，
並對 AI 相關貼文做「是否值得作為深化方向」的評估。每天一份紀錄存在 `daily/YYYY-MM-DD.md`。

## 怎麼傳貼文給 Claude（建議順序）

1. **直接貼上文字**（最可靠）：作者 + 內文 + 連結。
2. **截圖**：可以，Claude 會讀圖。
3. **只有連結**：Threads 多數需登入，Claude 常抓不到內容，所以請盡量附上文字或截圖。

格式隨意，例如：

```
1. @作者 https://www.threads.net/...
   （貼上內文）
2. ...
```

## Claude 的處理流程

1. **分類**：AI 相關 / 職涯・學習 / 工具・效率 / 其他。
2. **一般貼文 → 行動計劃**：每則濃縮成一句重點 + 具體下一步（含預估時間）。
   沒有可行動之處的，標「僅參考」，不硬湊任務。
3. **AI 貼文 → 深化評估**（見下方評分表），給出結論：
   - 🟢 **深入**：值得排進學習計劃，附具體第一步。
   - 🟡 **觀察**：先收藏，等有更多訊號再決定。
   - 🔴 **略過**：炒作、與方向無關或資訊不實，說明原因。
4. **今日優先 Top 3**：從所有行動中挑最值得今天做的三件。
5. 寫入 `daily/YYYY-MM-DD.md`，並更新下方「AI 方向追蹤」。

## AI 貼文評分表（每項 1–5 分）

| 面向 | 問題 |
|---|---|
| 與我方向的契合度 | 跟「我的 AI 深化方向」（見下）有多相關？ |
| 可實作性 | 能否在一週內動手做出小東西驗證？ |
| 持久性 | 是長期趨勢/基礎能力，還是短期話題？ |
| 可信度 | 有原始來源、實測或程式碼嗎？還是二手轉述/炒作？ |
| 槓桿 | 學會後能否用在現有專案（如 BigLens）或工作上？ |

總分 ≥ 19 → 🟢；13–18 → 🟡；≤ 12 → 🔴（Claude 可依理由微調並說明）。
