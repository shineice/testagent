# 大字閱讀鏡 (BigLens)

長輩把手機字體調得很大時,很多 App 的版面會爆掉:字被截斷(…)、被擠出畫面。
這個 Android App 用「無障礙服務」讀取目前畫面的完整文字,在自己的閱讀面板裡
以大字、自動換行、可滾動的方式重新顯示,不受原 App 版面限制。

## 使用
1. 用 Android Studio 開啟本專案並安裝到手機(minSdk 24)。
2. 開啟 App → 「前往開啟」→ 在系統無障礙設定打開「大字閱讀鏡」。
3. 在任何 App 點畫面上的藍色「字」浮動按鈕(可拖曳),即出現閱讀面板;可用「字 −/＋」調整大小,大小會被記住。

## 限制
- 只有 Android 可行;iOS 不允許第三方 App 讀取其他 App 的畫面。
- 圖片裡的字、遊戲、自繪畫面(沒有無障礙文字的)讀不到。
- 密碼欄位會被略過。文字只在手機本機處理,不上傳。
